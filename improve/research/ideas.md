## 표기

- **가능 여부** — `가능`(앱만 고치면 됨) · `서버 수정 필요`(`web/server.py` 등에 값·엔드포인트 추가) · `불가`
- **효과** 높음·중간·낮음 / **크기** 작음(반나절 안쪽)·중간(하루~이틀)·큼(그 이상)
- ⚡ = 속도·체감 성능 항목
- 이미 있는 것은 뺐다: 비교 표 파일 캐시 먼저 그리기, 자동 새로고침·틱·체결 플래시·흐림, 미니 캔들, 헤더 탭 정렬, 시장 전환·보유 필터, 캔들 길게 눌러 시고저종, 평단선·매매 마커, 차트 확대 창, x구간 기억, 1분봉, MACD·RSI, 원/$ 전환, 비중 파이, 자산·평가손익 추이, 매매 일지, 보조 주소 자동 전환, 끊김 시 자동 재시도, gzip.

## A. 효과 높음 · 크기 작음

### 1. ⚡ 포트폴리오도 지난 값 먼저 (계좌 파일 캐시)
- **어디서** 토스증권(열면 내 자산이 먼저), 옛 M-STOCK("당일 ± 만 빨리 확인"), 캐시 먼저 보여주기 일반 원칙
- **우리 앱** `data/TossSync.kt` (`accountCache` 가 메모리뿐) · `data/Snapshots.kt` · `ui/PortfolioScreen.kt`
- **가능 여부** 가능. 비교 표가 이미 하는 방식(`OverviewRepo.restore/persist`, `compare_cache.json`)을 계좌·스냅샷에 그대로 옮긴다.
- **효과 높음 / 크기 작음** — 지금은 앱을 새로 켜면 "계좌 정보를 불러오는 중…" 글자만 보인다. 총자산은 이 앱을 여는 가장 흔한 이유다. 지난 값 + 시각을 먼저 그리고 조용히 바꾼다.

### 2. ⚡ 종목을 바꿔도 스피너 대신 지난 차트 먼저
- **어디서** Webull·TradingView(종목 전환이 즉시), 영웅문 불만("장중에 느려서 못 쓴다")
- **우리 앱** `ui/AnalysisViewModel.kt` — `select()` 가 `result = null` 로 비우고 `CircularProgressIndicator` 를 띄운다
- **가능 여부** 가능. 종목별 분석 응답을 메모리 LRU(예: 최근 12종목)에 두고, 있으면 그걸 먼저 그린 뒤 조용히 갱신. 파일에도 남기면 앱을 새로 켠 직후에도 통한다.
- **효과 높음 / 크기 작음** — "이전 종목 차트가 남아 보이는 문제" 때문에 비웠던 것이므로, **그 종목 자신의** 지난 결과만 쓰면 원래 문제는 다시 생기지 않는다.

### 3. ⚡ 분석 프리페치 — 누르기 전에 받아 둔다
- **어디서** 프리페치 일반 원칙(다음에 갈 화면의 캐시를 데워 둔다)
- **우리 앱** `ui/CompareViewModel.kt` · `ui/AnalysisViewModel.kt` · `data/Server.kt` `analysis()`
- **가능 여부** 가능. 서버는 이미 `_warm_analysis` 로 계산을 끝내 둔다 — 폰이 **받아 오기만** 하면 된다. 비교 표가 그려진 뒤 보유 종목 → 화면에 보이는 위쪽 행 순으로 2~3개씩 천천히. 2번의 캐시에 넣는다.
- **효과 높음 / 크기 작음** — 요청을 한꺼번에 쏘지 말 것(터널 대역·서버 부하). 와이파이일 때만, 손가락을 댄 직후엔 쉬는 식으로.

### 4. ⚡ 앱 시작 때 세 탭을 한꺼번에 데운다
- **어디서** 캐시 먼저·병렬 로드 일반 원칙
- **우리 앱** `ui/AppScaffold.kt` — 지금은 `Store.syncFromServer` 가 끝난 뒤 **들어간 탭만** 받는다
- **가능 여부** 가능. 동기화 직후 `compare(보는 시장)` · `account` · `snapshots` · 마지막에 본 종목 `analysis` 를 동시에 보낸다(포트폴리오 `reload` 가 이미 셋을 병렬로 보내는 것과 같은 방식).
- **효과 높음 / 크기 작음** — 탭을 처음 누를 때마다 기다리는 일이 없어진다.

### 5. 분석 탭 안에서 이전/다음 종목으로 넘기기
- **어디서** Webull(관심목록 → 종목 → 다음 종목), TradingView 관심목록 넘기기, mPOP '최근사용'
- **우리 앱** `ui/AnalysisScreen.kt` — 종목 칩 줄 `TickerBar` 가 **정의만 있고 호출되지 않는다.** 지금은 비교로 돌아가야 종목을 바꿀 수 있다.
- **가능 여부** 가능. 하단 바(`BottomActionBar`)에 `‹ ›` 를 두고 **비교 표의 현재 정렬 순서**대로 넘긴다. 차트가 가로 드래그를 쓰므로 스와이프는 머리글 줄에서만 받는다.
- **효과 높음 / 크기 작음** — 2·3번과 합치면 종목을 훑어보는 속도가 크게 달라진다.

### 6. 비교 표 열 바꾸기 (주간·고점대비·β·σ)
- **어디서** Webull·영웅문 관심종목 열 편집, 증권플러스
- **우리 앱** `ui/CompareScreen.kt` · `ui/CompareViewModel.kt` — `SortKey` 에 `WEEK·FROM_HIGH·BETA·SIGMA` 가 있고 서버도 값을 주는데 **화면에 열이 없다**
- **가능 여부** 가능. 오른쪽 두 열(Z·M)을 탭 한 번에 `Z·M → 주·고점 → β·σ` 로 돌린다. 선택은 `Store` 에 기억.
- **효과 높음 / 크기 작음** — 이미 받고 있는 데이터를 보여주기만 한다. Webull 가로 모드처럼 열을 끝없이 늘리지는 말 것(불만 사례).

### 7. 보유 행 표시 전환: 평가손익 ↔ 오늘 손익
- **어디서** 토스증권(추측 — 보유 목록의 표시 전환), Delta "무엇이 내 포트폴리오를 움직였나", 옛 M-STOCK
- **우리 앱** `ui/PortfolioScreen.kt` `TossBody` 보유 목록 — 지금은 누적 손익·수익률만
- **가능 여부** 가능. `LivePrices` 현재가와 전일 기준가(`dailyPnlRate` 로 역산 — SESSION_NOTES 에 방법 기록됨)로 종목별 오늘 손익(금액·%)을 낸다. 행 오른쪽을 탭하면 전환.
- **효과 높음 / 크기 작음** — 히어로의 "오늘 ±" 가 **어느 종목 때문인지** 바로 보인다.

## B. 효과 높음 · 크기 중간

### 8. 지정가 알림 (로컬)
- **어디서** 토스증권, Robinhood(차트 종 아이콘), TradingView(가격 수준 길게 눌러 생성), 증권플러스
- **우리 앱** 신규 `data/Alerts.kt` + 워커 · `ui/AnalysisScreen.kt`(설정) · `AndroidManifest.xml`(POST_NOTIFICATIONS)
- **가능 여부** 가능, 다만 **지연이 있다.** 푸시 서버가 없으므로 WorkManager(최소 15분 간격)로 `/api/prices` 를 조회해 로컬 알림. 더 촘촘히 하려면 장중에만 포그라운드 서비스.
- **효과 높음 / 크기 중간** — 남의 불만에서 배울 것 네 가지:
  - 종목 화면에 **알림이 걸려 있는지 표시**(영웅문 불만)
  - 알림에 **메모 한 줄**(Investing.com 불만: "왜 걸었는지 모르겠다")
  - **한 번 울리면 꺼지거나 구간당 한 번**(TradingView 불만: 몇 초 사이 연발)
  - **방해금지 시간**(증권플러스) · 기본값은 전부 꺼짐(Webull 불만: 알림 폭탄)

### 9. Z·M 구간 진입 알림
- **어디서** 우리 앱 고유 — 남의 앱의 "지표 알림"(TradingView)을 우리 점수로
- **우리 앱** 8번의 워커 + `data/Server.kt` `compare()` (zPct·mPct 가 이미 온다)
- **가능 여부** 가능. 일봉 기준 값이라 15분 지연이 문제가 안 된다 — **지정가 알림보다 이 앱에 더 잘 맞는다.**
- **효과 높음 / 크기 중간(8번이 있으면 작음)** — "Z ≤ 20 진입", "M 이 80 을 넘음" 을 보유·관심 종목에 대해. 하루 한 번만.

### 10. 홈 화면 위젯
- **어디서** Stock Events, Delta(단일 종목·상하위·포트폴리오), TradingView
- **우리 앱** 신규 Glance 위젯 · 1번의 계좌 파일 캐시 · `compare_cache.json`
- **가능 여부** 가능. 위젯은 **파일 캐시를 읽어 그리고**, 갱신은 8번 워커가 겸한다.
- **효과 높음 / 크기 중간** — 남의 위젯 불만이 전부 "빈 화면"이다(증권플러스: 재부팅 후, Yahoo·Stock Events: 업데이트 후). **값이 없으면 지난 값 + 시각**을 그리면 그 문제가 안 생긴다. 두 종류: ① 총자산·오늘 손익 ② 관심 5종목 미니 표.

### 11. 벤치마크 대비 내 수익률 선
- **어디서** Sharesight(벤치마크), Snowball, 더리치(S&P 500 대비 백테스트)
- **우리 앱** `ui/PortfolioScreen.kt` 평가손익 차트 · `ui/Charts.kt` `EquityChart` · `web/server.py` `/api/snapshots`
- **가능 여부** 서버 수정 필요. 스냅샷 날짜에 맞춰 SPY(이미 받는 일봉)·KOSPI 대용 종가를 같이 내려 준다. 입금은 `Deposits` 로 보정.
- **효과 높음 / 크기 중간** — "시장보다 잘하고 있나"는 지금 화면 어디에도 없다. 예전에 TWR 을 뺀 이유(매매기록 불완전)와 겹치지 않게, **스냅샷 총자산 + 입금 장부**만으로 계산한다.

- **어디서** 토스 수익분석(추측), mPOP 실현손익 기간 조회
- **우리 앱** `ui/PortfolioScreen.kt` · `web/server.py` `/api/journal`
- **가능 여부** 서버 수정 필요. 체결내역으로 평균단가법 계산.
- **효과 중간 / 크기 큼** — 예전에 실현손익을 **매매기록이 불완전해서 뺐다.** 체결내역 수집 시작 이후 구간만, "이 날짜부터"를 명시해 보여줄 수 있을 때만.

### 42. 거래량 막대
- **어디서** 모든 증권사 차트
- **우리 앱** `data/Candle.kt`(거래량 필드 없음) · `ui/Charts.kt` · `web/`
- **가능 여부** 서버 수정 필요. **확인 필요** — 토스 캔들 응답에 거래량이 있는지 먼저 본다.
- **효과 낮음 / 크기 중간** — 일봉 스윙 판단에 Z·M 만큼 쓰이지 않는다.

### 43. 매매 일지 필터·메모
- **어디서** 더리치 매매일지, 영웅문 자동일지, Investing.com 불만(메모 없음)
- **우리 앱** `ui/PortfolioScreen.kt` `TradeJournal`
- **가능 여부** 필터는 가능, 메모는 서버 수정 필요(체결 ID 에 메모 붙이기). SESSION_NOTES H2 로 미뤄 둔 것.
- **효과 낮음 / 크기 중간**

### 44. 햅틱
- **어디서** Robinhood 차트 스크럽(추측)
- **우리 앱** `ui/Charts.kt` `chartGestures`(길게 눌러 봉을 넘길 때) · 정렬 전환
- **가능 여부** 가능
- **효과 낮음 / 크기 작음** — 봉 하나 넘어갈 때마다 약한 틱. 과하면 거슬린다.

### 45. 다음 휴장일·조기 마감 표시
- **어디서** 토스 증시캘린더, 증권플러스 투자 캘린더(실적 일정은 우리 데이터에 없다 — **불가**)
- **우리 앱** `data/MarketHours.kt` · `web/market.py`
- **가능 여부** 서버 수정 필요(작음) — 장 운영시간은 이미 받는다. 며칠 앞까지 보게만 하면 된다.
- **효과 낮음 / 크기 작음** — `TickStatus` 에 `내일 휴장` · `오늘 02:00 조기 마감`.

### 46. 앱 아이콘 바로가기
- **어디서** mPOP '최근사용', TradingView 위젯 바로가기
- **우리 앱** `AndroidManifest.xml` · `MainActivity.kt`
- **가능 여부** 가능 (App Shortcuts). 아이콘을 길게 눌러 포트폴리오 / 마지막 종목.
- **효과 낮음 / 크기 작음**

### 47. 가로 화면 전체 차트
- **어디서** TradingView("must-have"), Webull
- **우리 앱** `ui/AnalysisScreen.kt` 확대 창 · `AndroidManifest.xml`
- **가능 여부** 가능
- **효과 낮음 / 크기 중간** — 이 앱은 세로·한 손이 전제다. 확대 창을 **그 창에서만** 가로로 돌리는 정도면 충분.

## 하지 말 것 (남의 불만에서)

- 알림을 기본으로 켜 두지 않는다 (Webull).
- 화면 배치·제스처를 예고 없이 바꾸지 않는다 (TradingView 스크리너, Yahoo 기간 버튼).
- 값이 없을 때 빈 화면·0을 그리지 않는다 — 지난 값과 시각을 그린다 (위젯 불만 전부, 더리치 0원 항목).
- 종목 이름을 자르지 않는다 — 밀도를 올릴 때 확인 (M-STOCK, Yahoo).
- 업데이트를 강제하지 않는다 (영웅문).
- 가짜 항목으로 숫자를 맞추지 않는다 — 원금은 지금처럼 사용자가 적은 입금 장부만 (Delta 의 합성 '입금').
